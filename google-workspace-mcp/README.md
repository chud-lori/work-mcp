# Google Workspace MCP

Read-only MCP server for Google Workspace content:

- Google Drive search and file metadata
- Gmail search and message text
- Google Docs text extraction
- Google Sheets values extraction

This is intended for company-doc access through OAuth with least-privilege read-only scopes. Do not commit OAuth credentials or token files.

See [COMMANDS.md](./COMMANDS.md) for setup, auth, and handoff steps.
